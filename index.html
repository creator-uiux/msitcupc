IT Service & Maintenance Management System

Functional · real-time · v2

A working, real-time implementation of Maintenance System.pdf: the Office IT Service Request, Maintenance and Closure workflow (29-step SOP + 4-lane swimlane). Every screen runs the actual workflow engine in the browser (js/flow.js): guarded transitions, role-based access, live notifications, automatic reminders and schedule checks, persisted in localStorage and synced across tabs. Layout switches at 1024 px and exports to Figma with python tools/shots.py (deterministic ?demo=1 frames).

A zero-dependency Python + SQLite backend (server/) runs the same engine with server-enforced RBAC, background workers and Server-Sent Events. Start it with python server/app.py and open http://127.0.0.1:8787/. Every page is then live against the backend. See server/README.md and BACKEND.md.

The published site runs the same engine in the browser, so the whole workflow works with no server: the records live in the browser and the role still decides what each person may do. Point the site at a running backend and it switches to the live service on its own.
